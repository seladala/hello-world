# Ultimate Hello World 🤝

Самый переусложнённый способ вывести две строчные буквы... то есть два слова.

```
$ python main.py
hello world
```

Внешних зависимостей нет, только стандартная библиотека Python 3.10+.

## Что происходит, пока вы ждёте ~1 секунду

1. **Резолвер зависимостей** читает `ultimate_hello/manifests/components.json`, проверяет
   semver-ограничения (`^`, `~`, `>=`, `<`...), ищет циклы и топологически сортирует
   12 компонентов.
2. **DI-контейнер** поднимает их по очереди и вызывает хуки `on_start`.
3. **Разогрев**: проверка гипотезы Коллатца, решето Эратосфена (сверка с π(20000) = 2262),
   детерминант единичной матрицы через метод Гаусса на дробях, bogosort. Результаты
   складываются в **пул энтропии**, который их торжественно выбрасывает.
4. **Консенсус по числу π**: Чудновский (binary splitting), формула Мачина и спигот
   Гиббонса считают 1000 знаков, и кворум оракулов голосует за результат.
5. **Эмулятор процессора UHX-16** (16 бит, 8 регистров, стек, флаги, порты ввода-вывода):
   - `post.asm`: самотестирование при включении (fib(20) = 6765 и проверка RAM);
   - `hello.asm`: приветствие хранится в зашифрованном виде, ключ каждого символа
     вычисляется из цифр π (`(d*13 + 37) & 0xFF`), а умножение сделано сдвигами и
     сложением, потому что опкод MUL «слишком удобный».
   Прошивка каждый раз собирается из исходников **двухпроходным ассемблером** и
   прогоняется через **дизассемблер**.
6. **Комитет по утверждению глифов**: пять чиновников голосуют за каждую букву,
   у Chief Hello Officer есть право вето.
7. Каждое одобрение майнится в блокчейн **GlyphChain** с proof-of-work.
8. **Переговоры о регистре** идут в четыре раунда (UPPER → Title → Sentence → lower).
9. Длина строки проверяется в **арифметике Пеано**.
10. 64-битный отпечаток сообщения проходит через **4179 слоёв соответствия** в `main.py`.
    Каждый делает обратимое преобразование (умножение на обратный по модулю 2⁶⁴,
    ротации, двойной XOR, …) и проверяет, что ничего не изменилось.
11. **Движок рендеринга** собирает символы из событий шины и превращает их в фотоны.

`python main.py -v` показывает всю бюрократию в stderr, `-vv` выводит отладку,
а `--disassemble` печатает машинный код.

## main.py

Ровно **67 000 строк**. Файл генерируется скриптом:

```
python tools/generate_main.py            # пересобрать main.py
python tools/generate_main.py --lines N  # другая длина, если 67k кажется мало
```

## Структура

```
main.py                         67 000 строк, точка входа
tools/generate_main.py          генератор main.py
ultimate_hello/
  bootstrap.py                  Kernel: граф зависимостей → DI → жизненный цикл
  di.py                         IoC-контейнер
  events.py                     шина событий
  config.py, enterprise.ini     конфигурация
  services.py                   PiService, FirmwareLoader, CpuService, GreetingService
  manifests/components.json     манифест компонентов с версиями и зависимостями
  deps/                         semver и топологический резолвер
  cpu/                          ISA, ассемблер, эмулятор, дизассемблер, программы .asm
  pi/                           Чудновский, Мачин, спигот, протокол консенсуса
  bureaucracy/                  комитет, переговоры о регистре, блокчейн GlyphChain
  rendering/                    движок рендеринга в терминал
  useless/                      Пеано, пул энтропии, разогрев
tests/                          python -m unittest discover -s tests
```
